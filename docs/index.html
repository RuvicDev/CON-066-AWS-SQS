1. ¿Qué es y para qué sirve?

AWS SQS es el servicio de colas de Amazon para desacoplar sistemas mediante mensajes. Permite enviar, recibir y procesar mensajes de forma confiable.

OperaciónQué hace
queue.send_messageEnvía un mensaje a la cola configurada.
queue.receive_messagesRecibe mensajes con long polling.
queue.delete_messageElimina un mensaje, bloqueado por defecto.
queue.get_queue_attributesConsulta atributos de la cola.

2. Prerrequisitos

  • Cuenta AWS con SQS habilitado.
  • Región AWS definida.
  • Queue URL de una cola SQS de prueba o producción.
  • Usuario/rol IAM con permisos mínimos.

3. Configuración en AWS

  1. Crea o identifica la cola SQS.
  2. Copia la Queue URL.
  3. Crea credenciales IAM de mínimo privilegio.
    [ Captura: cola SQS y política IAM — reemplazar si aplica ]

4. Permisos requeridos

sqs:GetQueueAttributesProbar conexión y consultar métricas de cola.
sqs:SendMessageEnviar mensajes.
sqs:ReceiveMessageRecibir mensajes.
sqs:DeleteMessageEliminar mensajes si se habilita explícitamente.

5. Configuración en Ruvic

Completa Access Key, Secret, región, Queue URL y parámetros opcionales de long polling, visibility timeout y borrado autorizado.

6. Verificación

Ejecuta Probar conexión, consulta atributos, envía un mensaje de prueba y recíbelo. Eliminarlo requiere autorización explícita.

7. Solución de problemas

AccessDeniedFaltan permisos IAM o región incorrecta.
QueueDoesNotExistQueue URL incorrecta o cola en otra región.
Delete bloqueadoActiva ALLOW_DELETE_MESSAGE solo para uso autorizado.

8. FAQ y seguridad

Usa IAM de mínimo privilegio, no subas claves, procesa mensajes de forma idempotente y elimina mensajes solo después de confirmar procesamiento correcto.
